## End-to-end artifact evidence

The reviewed baton example used Standard 1024 geometry, the 1024 denoiser and a 2048 × 2048 base-color atlas. It completed in 499 seconds and produced a 22,138,764-byte GLB with 357,819 vertices, 662,201 triangles and no fallback events.

The repository tests independently decode the GLB and verify its geometry counts and embedded PNG dimensions. See `examples/baton-uv2048/result.json` for the sanitized measured record.

## Scope and limitations

- This is evidence for one reviewed hardware/software configuration, not universal AMD support.
- Installation and extension readiness do not install full ComfyUI/TRELLIS.2 sources or model weights.
- No production generation capability is enabled by this toolkit.
- Absence of micro-freezes or future driver stalls is not proven.
- GPU verification is sequential and manual; public CI performs only no-GPU integrity checks.
